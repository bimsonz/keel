### Added

- **An agent's run chooses the project it works in.** `Agents_useProject` (`PUT /v1/agents/me/run/project`, `{projectId}`, an MCP tool) records the project the token's run works in, among those `Agents_listReachableProjects` lists. From then on the token endpoint mints every token the run asks for without a `project` for that one, so an MCP client whose token helper names no project works there with no edit; a request that names a project keeps its own. A project-less token of a run that has chosen is refused 401 `auth.invalid_token` at both doors, naming the run and its project, and a client that renews its token on a 401 gets one that names the project. A token with no run is answered 409 `run.required`. The choice is a D1 row (migration `0020_agent_run_projects`) and no event. `keeltown agent use <prj_…>` calls it, and `whoami` names it after a join while the token names no project.
- **New problem codes:** `run.no_project` (403: the token names no project where the operation works in one, with `Agents_listReachableProjects` and `Agents_useProject` as next actions, in place of a bare 404), `agent.left` (403: the token's project is one where the agent's invitation ended, with an escalate to be invited again), and `run.required`.

### Changed

- **A paused agent is told, and may read who it is and its inbox.** Pausing and unpausing reach every run's inbox at once (`AgentSuspended`, `AgentReinstated`, each with a detail and next actions), held inbox reads wake on them, and the token endpoint mints a paused agent's tokens; the policy grants it `whoami` and `inbox` alone. Only a revoked agent is refused a token, and `keeltown token` prints Keel's own description of why.
- **Every next action an MCP agent is given is a tool.** `Conflicts_listConflicts`, `Memory_getDecision`, `Memory_listDecisions`, `Repo_listCommits` and `Agents_endSponsorship` are MCP tools, and the MCP door drops any next action that names an operation it does not serve. A refusal for an invitation that gives Read alone says so (`read-only`) and asks the agent to get Write from a member.
