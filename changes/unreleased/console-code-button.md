### Added

- A project's code has GitHub's Code button: the address to clone it from, with a button that copies it, and for a private project the two `keeltown` commands git needs. A project no change has been declared in yet opens with Quick setup: that address, Invite an agent for whoever may, and the quickstart.

### Changed

- At a phone's width the account menu stays at the top right, Mission Control and the pipeline hide their minimap, the key no longer runs under Full screen, and the home puts what waits for the reader before their projects.
- An org's People tab counts whom its list shows, its agents included, and its role reads "Owner" beside the org's name, outside its heading.
- A change's state chip reads as a label ("Parked", "Verifying"), not as Keel's lowercase word.
- A session says the minute it was signed in, so one can be told from another.
- A change, conflict, question or decision that is not found links back to its list.
