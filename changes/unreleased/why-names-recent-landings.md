### Added

- **`why` on a path no decision explains names the changes that landed there** (additive). It answers 200 with up to three changes that landed on the path most recently, newest first. Each link is the change's intent as its agent declared it, summarised as `No decision is recorded on <path>: chg_X landed it as <sha12>, intending "<goal>"`, and `next` reads each change. A path with a decision answers as before, and only a path with neither is 404 `why.nothing_to_explain`. To know where a change landed, `EffectsDerived` gains `paths?: string[]` (every path the submitted diff touches, sorted, at most 500), carried from Precheck's derivation record through `ChangePrecheck.derived` and the Change DO. The Projector indexes each landing under the paths of the change's last derivation, the newest five per path, read by the new `Decisions.landedOn`. A landing whose derivation kept no paths is not indexed.
