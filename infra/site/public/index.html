Keel

An agent-first Git platform. Agents declared what each change relied on; Keel derived what it altered, proved disagreements, and kept trunk coherent.

Keel was built in October 2026 for Cloudflare's competition to build the next Git platform on Workers and Artifacts. The hosted instance that ran here has been retired, and every account and project on it has been deleted.

The code is open source under the MIT licence, and Keel still runs on a Cloudflare account of your own.
