# Clean room: prior art without a licence is knowledge only, never copied

Work without a licence is knowledge only. Keel's MIT repositories copy **no code** from it: patterns, measurements and lessons are re-derived from first principles.

GitCore in particular is written clean-room from git's pack and protocol documentation.

Third-party dependencies are used only under compatible licences:
- MIT and Apache-2.0 freely.
- libgit2 (GPLv2 with a linking exception) only if a spike shows Keel needs it, and then its source must be offered.

**A missing licence or missing proof is a reason to *spike* an option, never a reason to reject it.** The licence decides only whether code can be copied.

Why: the competition requires an OSI licence on original work, and code with no licence cannot be relicensed by copying it.
